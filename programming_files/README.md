# Programming references

This folder holds local reference projects used by the configured coding
workflow. Its README is tracked so a fresh checkout has the directory needed
for session previews and project setup. Downloaded projects remain ignored.

From the repository root, build the native player and run
`TutorialAutomation\build\tutorial.exe --fetch-projects` to fetch the projects
listed in `TutorialAutomation/profiles/projects.json` at their pinned commits.
The combined session can browse when no coding project is available.
